# Privacy deployment artifact

Place the reviewed production JSON at `deployment/privacy/deployment.json`. Docker Compose mounts this directory read only at `/run/privacy`, and `PRIVACY_CONFIG_FILE` points to that file. The JSON is excluded from Git because it can contain evidence references and the destruction evidence HMAC key.

Copy `docs/privacy-deployment.example.json` as a starting template. Fill every definition and evidence section from approved operator records, contracts, calendar, and retention decisions. Empty lists and blank evidence intentionally keep production readiness in `FAIL`. Do not copy test policies into production. The business calendar must cover today through at least the next 31 days, include the reviewed source reference and verification time, and be refreshed before coverage expires.

Definition rows use the PHP constructor parameter names of their corresponding `*Definition` class as JSON keys. Date fields (`activeFrom`, `activeUntil`, `notificationSubmittedAt`, `regulatorReviewUntil`) use timestamps with offsets. The loader rejects unknown fields and unresolved purpose references. The distribution consent document version and SHA-256 are configured here and are never accepted from API clients. A deployed file must include all sections shown in the template. `privacyDestructionEvidence.hmacKey` must be provisioned as a secret and its retention duration reviewed for at least three years. `privacyLegalEvidence` records the system name/code and destruction method, with processor name/address when applicable.

Provision `commercial.privacy_operators` with an authorized Control User ID and authorization reference before using `/api/control/privacy/operator/requests/intake`, `/requests/{id}/resolve`, and `/incidents`. The request body binds a verified non-user subject to a billing profile, invoice, or receipt ID and records an external identity evidence URN. Financial snapshots remain immutable when mutable billing contacts are corrected or erased.
For an identified individual without a direct record link (`subjectKind: "other"`), resolving access or processing information requires `responseEvidenceReference` pointing to the reviewed external response document.

Set `CONTROL_PRIVACY_OPERATOR_NOTIFICATION` to a reviewed JSON object. When required, include `required: true`, `status: "submitted"`, `number`, `date`, `evidence_reference`, `registered_purposes`, and `database_location_reference`. If a reviewed exemption applies, set `required: false` and `exemption_reference`. Run `php bin/console control:privacy:check` in the Control Plane deployment to inspect missing evidence. The Core compliance check reports missing calendar, operator, RKN, security, residency, and destruction evidence separately.
