# Будущий API собственных сессий

Сценарии использования приложения подготовлены для маршрутов:

- `GET /api/account/sessions`;
- `POST /api/account/sessions/{id}/revoke`;
- `POST /api/account/sessions/revoke-others`.

Маршруты намеренно не зарегистрированы. Для них нужна доверенная аутентифицированная
серверная идентичность, предоставляющая идентификаторы аккаунта и текущей сессии.
Ни один из этих идентификаторов нельзя принимать из query-параметров или JSON как
указание на то, чьи это «мои сессии».
