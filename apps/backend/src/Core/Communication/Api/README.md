# API Communication

В Communication пока нет публичного HTTP API. Доменные модули помещают события
в очередь через сервисы приложения, а консольный обработчик их обрабатывает.

В локали полезной нагрузки письма используется общий контракт BCP 47 (`ru-RU`, `en-US`).
Для совместимости устаревшие значения `ru` и `en` нормализуются.
