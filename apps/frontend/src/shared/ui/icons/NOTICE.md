# Локальные изображения значков

Значки Solar Linear, автор **480 Design**:
[исходный проект](https://github.com/480-Design/Solar-Icon-Set),
[исходный файл Figma](https://www.figma.com/community/file/1166831539721848736).
Лицензия: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Выбранные SVG взяты из локальной коллекции Solar пользователя. Цвета заменены на `currentColor`; файлы переименованы и объединены в символы.
`spinner.svg`, `calendar.svg` и `clock.svg` созданы для приложения и не относятся к Solar.

`svg/` содержит редактируемые исходники; `sprite.svg` создаётся командой `npm run generate:icons` и проверяется `npm run check:icons`.
