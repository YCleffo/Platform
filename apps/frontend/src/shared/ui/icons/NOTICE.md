# Local icon artwork

Solar Linear icons by **480 Design**:
[original project](https://github.com/480-Design/Solar-Icon-Set),
[original Figma](https://www.figma.com/community/file/1166831539721848736).
License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The selected SVGs were taken from the user's local Solar collection. Colors were
changed to `currentColor`, and files were renamed and combined into symbols.
`spinner.svg`, `calendar.svg` and `clock.svg` are application-authored artwork, not Solar artwork.

`svg/` contains editable sources; `sprite.svg` is generated with
`npm run generate:icons` and verified by `npm run check:icons`.
