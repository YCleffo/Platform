# Контракт графиков и аналитики (на будущее)

Статус: **только контракт**. Графиков, дашбордов, `ChartService`, `AnalyticsStore` и
`AppChart` сейчас нет, и их нельзя создавать, пока не появится реальный экран. Этот
документ фиксирует границы, чтобы будущая реализация не перестраивала архитектуру.

## Принципы

1. **Числа — типизированные данные, а не строки форматирования.** API/адаптеры отдают
   числа (и `null` для отсутствующих точек); форматирование — только при отрисовке.
2. **Деньги остаются целыми минорными единицами** до отображения. Никакой арифметики
   бизнес-расчётов через JavaScript floating-point; `shared/formatting/money.ts` делит
   только для показа.
3. **Форматирование отделено от API.** Деньги / проценты / дата-время / единицы живут в
   `shared/formatting/*`, а не в HTTP-клиенте или сторах.
4. **Компонент графика никогда не обращается к HTTP-клиенту.** Поток данных:
   `адаптер модуля → composable/store модуля → props графика`.
5. **Адаптеры данных принадлежат модулям.** Транспорт остаётся единым; модуль
   преобразует ответ в общую модель графика.
6. **Рендерер заменяем.** Компонент графика принимает только props, поэтому библиотеку
   можно заменить без изменения бизнес-логики.
7. **Цвета — существующие domain/status токены** (`--color-domain-*`, статусы), не
   произвольные hex.
8. **Отсутствующие значения — `null`, не `0`.** Пропуски рисуются как пропуски.
9. **Доступность и читаемость на 320px обязательны** (см. ниже).

## Общая модель данных (добавляется вместе с первым реальным графиком)

```ts
type Unit = 'count' | 'percent' | 'money_minor' | 'bytes' | 'duration_ms' | 'custom';

interface MetricValue {
  value: number | null;
  unit: Unit;
  currency?: string; // обязателен при unit === 'money_minor'
}

interface TimeSeriesPoint {
  at: string; // ISO-8601 instant (UTC), не локальная строка
  value: number | null;
}

interface TimeSeries {
  id: string;
  labelKey: string; // i18n-ключ, не захардкоженная подпись
  points: TimeSeriesPoint[];
  unit: Unit;
  currency?: string;
  timezone: string; // IANA-зона для подписей бакетов
}

interface MetricCard {
  id: string;
  labelKey: string;
  current: MetricValue;
  previous: MetricValue | null;
  delta: 'up' | 'down' | 'flat' | null;
}
```

## Граница адаптера

- Модуль отдаёт `useXxxAnalytics(range: DateRange)` (или store), который:
  - вызывает API модуля через общий транспорт,
  - валидирует ответ на границе (runtime-guards),
  - маппит в `TimeSeries` / `MetricCard`,
  - сохраняет `null` как `null`.
- Компонент графика получает `series: TimeSeries[]` и диапазоны только через props; он
  не знает про эндпоинты, авторизацию и правила денег.

## Диапазоны дат и часовые пояса

- `DateRange` явный: `{ from: string; to: string; granularity: 'hour'|'day'|'week'|'month' }`.
- Значения запрашиваются и группируются в именованной IANA-зоне; интерфейс показывает зону.
- Подписи осей и тултипы форматируются через `Intl.DateTimeFormat` с этой зоной.

## Состояния

Каждая поверхность графиков/аналитики обязана реализовать по порядку:
`loading` (скелетон без сдвига вёрстки) → `empty` (нет данных, отдельно от нуля) →
`error` (локализованная, с повтором) → `data`.

## Адаптивность и темы

- Mobile-first; читаемость на 320px обязательна. На узких экранах допустимы
  горизонтально прокручиваемая таблица или стек вместо широкого графика.
- Light и Dark используют одни семантические токены; захардкоженных цветов нет.
- Учитывать `prefers-reduced-motion` (без анимаций, если пользователь просил).

## Доступность

- У каждого графика есть доступное имя и текстовый/табличный эквивалент (скрытая таблица
  или переключаемая таблица данных).
- Смысл не передаётся только цветом: статусные цвета сопровождаются подписью/иконкой.
- Touch-target ≥ 44px; видимый клавиатурный фокус.

## Форматирование денег

- Денежные серии отображаются через `formatMoney(amountMinor, currency, locale)`.
- Агрегаты по деньгам считаются на сервере в целых минорных единицах; frontend никогда
  не суммирует деньги через floating-point для бизнес-значений.

## Вне рамок сейчас

Библиотека графиков (Chart.js/ECharts и т.п.) не установлена. Первый реальный график
добавляет ровно один рендерер за этими props, свой адаптер и тесты.
