# Поля и связи Core на русском языке

Актуальный [справочник базы данных](../SCHEMA_REFERENCE.md) строится из реальной
PostgreSQL. Он содержит все поля Core, Runtime и Commercial, SQL-типы, NULL,
DEFAULT, комментарии и физические внешние ключи.

Назначение доменов объяснено в [модели данных](../../core-data-model.md),
действия — на [графиках процессов](../../processes/README.md).
Этот путь сохранён для существующих ссылок. Историческая версия доступна в Git.
