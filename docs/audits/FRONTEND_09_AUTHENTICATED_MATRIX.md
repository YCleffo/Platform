## Динамические ссылки

Карточка каждой ссылки содержит исходный файл со строкой, тип действия, выражение назначения и классификацию. `VERIFIED` используется только при наличии запуска в Chromium с наблюдением конкретного перехода. `ROLE_RESTRICTED` описывает ролевую область, `CONTEXT_DEPENDENT` — данные маршрута или контекста, `INTERNAL` — изменение query или внутреннее описание навигации. `NOT_VERIFIED` требует отдельного сценария. Полный реестр находится в поле `navigation.runtimeLinks`. [Evidence JSON](frontend09-final-evidence.json)

Аудит разрешил 111 именованных маршрутов и 213 статических ссылок, отдельно отметил два фрагмента. Динамический реестр вырос со 131 до 133 выражений из-за новых переключений query в Core Settings и Privacy. Статический аудит завершился без сломанных маршрутов. Браузерное подтверждение отдельных действий оставлено в соответствующей записи, включая ярлыки Feature flags и Legal holds на Dashboard.

## Подход к доступности

Chromium проверяет фактические клавиатурные действия. Axe использует теги WCAG 2.0, 2.1 и 2.2. CSS viewport 320 px проверяет reflow, а фактический масштаб браузера учитывается отдельно. Для ручной проверки NVDA или VoiceOver остаются обход landmarks, доступные имена и описания диалогов, возврат фокуса, объявления валидации и статусов, активные вкладки и значения ползунка.
