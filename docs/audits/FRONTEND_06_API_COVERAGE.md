## Как проверяется матрица

1. PHP-инвентаризатор загружает реальный массив маршрутов Yii с `EDUCATION_ENABLED=1` и читает Symfony route attributes через reflection. Он извлекает обязательные права из Yii middleware, сведения о политиках из активного обработчика и правила Symfony firewall. Политики внутри сервисов остаются источником истины и привязаны к строке контроллера или классу действия.
2. Операции OpenAPI сопоставляются по методу и форме пути. Разрешаются ссылки на записи путей, учитываются префиксы из контрактов Education, DeviceManagement и Storage. В JSON сохраняется исходный путь каждого контракта. Операции из нескольких файлов считаются один раз.
3. Анализ TypeScript и скриптов Vue ищет HTTP-вызовы, описания действий workbench, компоненты и привязки в маршрутизаторе. Динамические вызовы с описанием в нескольких файлах имеют проверяемые по исходникам привязки. Автоматические кандидаты в `ui` показывают путь до маршрута, а scope в `test` описывает найденное свидетельство. Политика на сервере, доступность кнопки для роли, успешная мутация и подтверждение сохранения проверяются отдельно.
4. `FULL` требует подтверждённого пользовательского результата. `PARTIAL` фиксирует клиентский вызов и его доступные свидетельства. `MISSING` указывает отсутствие прямой интерактивной интеграции по итогам анализа. Для путей совместимости в строке указан действующий пользовательский сценарий. `DEPRECATED` требует явной отметки устаревания в контракте.

После установки Composer-зависимостей обоих PHP-приложений и npm-зависимостей frontend команды можно выполнить из корня репозитория.

```sh
node apps/frontend/scripts/frontend06-coverage.mjs
node apps/frontend/scripts/frontend06-coverage.mjs --check
```

Проверка `--check` сверяет снимок с текущими маршрутами, контрактами и найденными ссылками в исходниках. Скрипт не запускает сервисы и не подключается к БД.

## Пользовательские исключения

| Операция или группа | Состояние |
| --- | --- |
| `GET /api/education/curriculum-modules/{id}`, `GET /api/education/curriculum-lessons/{id}` | Вложенные редакторы работают с программой, модулями и уроками из ответа `GET /api/education/programs/{id}`. Индивидуальные операции чтения не вызываются. |
| `GET /api/education/parent/children/{studentId}` | Родитель использует данные контекста и отдельные разделы выбранного ребёнка. Самостоятельный запрос краткой карточки отсутствует. |
| Прямые передачи Education | У пяти операций прямой загрузки или выдачи байтов есть подписанные альтернативы в текущих пользовательских сценариях. См. причины по каждой строке JSON. |
| `GET /api/storage/file`, `PUT /api/storage/files` | Кабинет ученика использует подписанные Storage transfers. Эти два билетных маршрута не вызываются при браузерной передаче. |

Оставшиеся строки `PARTIAL` содержат источники и причину в JSON. Для приёмки продукта требуется подтвердить роли и доступные действия, сохранение результатов, ограничение чужого контекста и восстановление после ошибок.
