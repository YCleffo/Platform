# FRONTEND_09 — инвентаризация интерфейса

База `4cf8c6d40ea107f6da1c3265c97a098962b78615` содержит 188 Vue-компонентов, 107 файлов компонентных тестов и 58 скриптов. Исходный `Platform CI` прошёл 16 из 16 jobs. [Прогон 44988575194](https://github.com/YCleffo/Platform/actions/runs/44988575194)

Инвентаризация охватывает 12 областей и четыре группы свойств. Компоновка включает header, sidebar, bottom navigation, tabs и breadcrumbs. Компоненты включают cards, buttons, inputs, menus, dialogs, toasts, tables и filters. Стили включают типографику, цвет, spacing, radius, тени и иконки. Интеракция включает motion, responsive и accessibility. Исходники и наблюдения по каждой группе зафиксированы в [машинном реестре](frontend09-ui-inventory.json).
